1. Familias tipográficas en uso

El proyecto utiliza dos familias principales y una fuente de respaldo:

Familia Variante principal en uso Rol
Avenir LT Pro 65 Medium Cuerpo, UI, formularios, botones
Avenir Next Ultra Light Títulos hero y secciones grandes
Outfit 300 / 400 / 500 / 600 / 700 / 800 Fallback si Avenir no carga

2. Pesos tipográficos por uso

Uso Fuente Peso (font-weight)
Títulos hero (h1 grandes) Avenir Next Ultra Light 200 – 300
Palabra bold dentro del título Avenir LT Pro 65 Medium 700
Párrafos y subtítulos Avenir LT Pro 65 Medium 300
Labels pequeños (formularios) Avenir LT Pro 65 Medium 300
Valores seleccionados / precios Avenir LT Pro 65 Medium 400 – 500
Botones / CTA principales Avenir LT Pro 65 Medium 500 – 600
Títulos h1–h6 por defecto (CSS global) Avenir LT Pro 85 Heavy 800

3. Cómo están cargadas las fuentes

A) Avenir LT Pro / Avenir Next — Adobe Fonts (Typekit)

Se carga mediante una hoja de estilos externa en el <head> del layout principal (src/app/layout.tsx):

<link rel="stylesheet" href="https://use.typekit.net/jpo1mmh.css" />

Cómo funciona: Al cargar la página, el navegador hace una petición a los servidores de Adobe Fonts (use.typekit.net) y descarga las fuentes del kit jpo1mmh. Los pesos y variantes disponibles son los que estén activados dentro de ese kit en el panel de Adobe Fonts.

Punto crítico: Esta fuente depende de una conexión externa en cada visita. Si Adobe Fonts falla, tarda o es bloqueada por un ad-blocker, el navegador cae directamente en Outfit o en la fuente del sistema. No hay archivos locales de Avenir en el proyecto.

B) Outfit — Google Fonts via Next.js

Se carga en el mismo archivo src/app/layout.tsx usando el sistema nativo de Next.js (next/font/google):

import { Outfit } from "next/font/google";

const outfit = Outfit({
  variable: "--font-outfit",
  subsets: ["latin"],
  weight: ["300", "400", "500", "600", "700", "800"],
});

Cómo funciona: Next.js descarga los archivos de Outfit desde Google Fonts en el momento del build y los sirve desde el propio servidor del proyecto. Esto significa:

  • Sin peticiones externas en producción (cero dependencia de Google).
  • Aplica font-display: swap automáticamente.
  • Es la fuente más performante del proyecto.

4. Orden de fallback (font stack)

Así están declaradas las pilas en el código. El navegador usa la primera fuente disponible:

Variable CSS / constante Stack completo
FONT_HEADING
(títulos)		 Avenir Next Ultra Light → Avenir LT Pro 65 Medium → Avenir → Outfit → system-ui
FONT_BODY
(cuerpo / UI)		 Avenir LT Pro 65 Medium → Avenir LT Pro → Avenir → Outfit → system-ui
CSS global body Avenir LT Pro → Avenir → Outfit → var(--font-outfit) → system-ui
CSS global h1–h6 Avenir LT Pro 85 Heavy → Avenir LT Pro → Avenir → Outfit → system-ui

5. Archivos relevantes

Archivo Qué contiene
src/app/layout.tsx Carga de Outfit (next/font) y enlace al kit de Adobe Fonts (Typekit)
src/app/globals.css Definición global de font-family para body, h1–h6 y clases específicas
src/components/HeroSection.tsx Constantes FONT_HEADING y FONT_BODY aplicadas en inline styles
src/components/SearchForm.tsx Constante FONT (Avenir LT Pro 65 Medium) usada en toda la UI del buscador
public/fonts/ Vacío — no hay archivos de fuente locales.
